This is a collection of tools to work with blk assets from various particular chinese gacha games, it can decrypt, unpack, repack, and encrypt blk, encr, mhy0, mhy1, and blb3 files, and generate ec2b seeds. they're rough around the edges for sure but surely could still be useful...

works for hk4e client version (unknown, likely only up to 5.0), hkrpg client version (unknown, likely only up to 2.4), and nap client version 1.7 and below.
nap 2.0+, (at least) hk4e 5.0+, and (at least) hkrpg 3.0+ uses an incompatible compression algorithm. support is being worked on at this time.
