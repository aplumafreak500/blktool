This is a collection of tools to work with blk assets from various particular chinese gacha games, it can decrypt, unpack, repack, and encrypt blk, mhy0, and mhy1 files and generate ec2b seeds. they're rough around the edges for sure but surely could still be useful...

works for hk4e client version 4.5 and below, and nap client version 1.7 and below.
hk4e 4.6+ uses a different format that is not well understood atm; nap 2.0+ uses an unknown, incompatible compression algorithm (most likely still a variant of lz4 tho)
