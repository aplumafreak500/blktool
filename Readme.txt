This is a collection of tools to work with a particular chinese gacha game's blk assets, it can decrypt, unpack, repack, and encrypt blk and mhy0 files and generate ec2b seeds. they're rough around the edges for sure but surely could still be useful...

works for client version 4.5 and below. 4.6+ uses a different format that is not well understood atm

compile with gcc, I'm a little lazy rn to put together a proper makefile
